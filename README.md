# Personal Portfolio Website

A lightweight, multi-page portfolio website built with plain HTML and CSS.

## Project Structure

```text
.
├── index.html
├── styles/
│   └── styles.css
├── pages/
│   ├── stats.html
│   ├── epi.html
│   ├── about.html
│   └── more.html
└── README.md
```

## Technologies
- HTML5
- CSS3

## Features
- Multi-page navigation
- Lightweight structure with no external frameworks

## Usage
The website can be run locally by opening `index.html` in a web browser.
