# Personal Portfolio Website

A lightweight, multi-page portfolio website built with HTML, CSS, JS.

## Project Structure

```text
├── index.html  # app entry
├── css/        # styles 
├── pages/      # page definitions / contents
├── js/         # re-usable js code
├── pics/       # static resources
└── README.md
```

## Technologies
- HTML5
- CSS3
- JavaScript

## Features
- Multi-page navigation
- Lightweight structure with no external frameworks

## Usage
The website can be run locally by opening `index.html` in a web browser.
